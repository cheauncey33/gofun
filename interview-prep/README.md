# WHU Snack 面试材料入口

## 使用顺序

1. 先读 `00_CONTEXT_LOCK.md`，确认所有回答不偏离真实项目。
2. 再读 `TASKS.md`，选择当前要扩写或背诵的任务。
3. 项目面试优先读 `01_PROJECT_WHITEBOX.md`、`02_DATABASE_SCHEMA.md`、`03_API_DATA_FLOW.md`。
4. 简历追问优先读 `04_RESUME_DEEP_DIVE.md`。
5. 八股和场景题读 `05_KNOWLEDGE_KEYWORDS.md`、`06_SCENARIO_QA.md`。
6. 面经统计和模拟面试读 `07_INTERVIEW_REPORTS_INDEX.md`、`08_MOCK_INTERVIEW_BANK.md`。

## 维护规则

- 后续任何新增内容，都必须先对照 `00_CONTEXT_LOCK.md`。
- 如果发现项目代码与文档不一致，优先相信代码，并更新文档。
- 如果是生产扩展方案，必须明确写“当前项目未实现”。
- 如果引用外部面经，必须保留链接。
