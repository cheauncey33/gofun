# grabData — 种子数据

为 WHU Snack GO 准备的一批可直接导入的真实零食 / 用户数据。

## 文件

| 文件 | 内容 |
|------|------|
| `categories.json` | 8 个零食分类（坚果炒货、膨化食品、饼干糕点、糖果巧克力、肉类零食、蜜饯果干、饮料冲调、方便速食） |
| `products.json` | 40 款**真实存在的**市售零食（三只松鼠、卫龙、乐事、德芙、康师傅、螺霸王……），含真实品牌名、真实价位、库存、销量、描述、配图 |
| `users.json` | 20 个用户，含用户名、密码、手机号、头像、余额、武大宿舍（樱园 / 桂园 / 梅园 / 枫园 / 湖滨）、收货地址 |

## 数据真实性说明

- **商品**：全部为真实市售零食品牌与商品，价格参考真实零售价。
- **商品图 / 头像**：商品配图取自 Unsplash 免费图库的真实食物摄影（按品类匹配），头像取自 pravatar.cc 真实人像。所有图片 URL 均已实测可访问（HTTP 200）。直接热链品牌官方包装图不稳定且涉及版权，故采用免费可商用图库。
- **用户个人信息（姓名 / 手机号 / 地址）**：为**符合真实格式的合成数据**，不是真实个人。手机号使用合法运营商号段但非真实号码，地址基于武汉大学真实校区与宿舍区编排。
  > 出于隐私考虑，不会也无法去抓取真实个人的电话与住址 —— 只有商品本身是真实世界中的商品。

## 导入到数据库

导入器在 `backend/cmd/seed`，读取本目录 JSON 后通过 GORM 写入 MySQL（自动生成雪花 ID、bcrypt 加密密码）。

在 `backend/` 目录下执行：

```bash
go run ./cmd/seed -config ./config/config.yaml -data ../grabData
```

- **幂等**：按分类名 / 商品名 / 用户名判重，已存在则跳过，可重复运行。
- 导入商品后**重启后端**，`main.go` 启动时会把库存预热进 Redis（`snack:stock:<id>`）。
- 导入的 20 个用户默认密码均为 `123456`。
